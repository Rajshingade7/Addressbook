# Address Book

A contact management application built with TypeScript. Allows users to add, view, edit, and delete contact information with a structured and type-safe codebase.

## Features

- Add new contacts with name, phone, email, and address
- View all contacts in an organized list
- Edit and update existing contacts
- Delete contacts
- TypeScript for type safety and better developer experience

## Tech Stack

- **TypeScript** — Strongly typed JavaScript
- **JavaScript** — Runtime execution

## Getting Started

### Prerequisites

- Node.js (v14+)
- TypeScript (`npm install -g typescript`)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Rajshingade7/Addressbook.git
   cd Addressbook
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Compile and run:
   ```bash
   tsc
   node dist/index.js
   ```
